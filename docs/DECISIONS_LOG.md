## Decisiones que exceden o contradicen el código y quedan pendientes de validar

- Imponer siempre exactamente 3–5 diapositivas también en el editor manual: el código actual permite crear hasta 20 y el backend tolera hasta 7.
- Integrar el constructor de carruseles dentro de la SPA: actualmente es un HTML autónomo.
- Añadir publicación automática: no existe endpoint ni permiso implementado.
- Tratar TikTok o YouTube Shorts como fuentes API: el repositorio solo confirma importación CSV.
- Añadir usuarios, roles, revisión multiusuario o aprobación por workflow: no existe en el modelo actual.
- Registrar costos, prompts y respuestas de IA de forma persistente: actualmente solo hay diagnósticos en consola.
